## 数据库结构

### recipes 表（菜谱）

```sql
CREATE TABLE recipes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,              -- 标题
    description TEXT,                 -- 描述
    content TEXT NOT NULL,            -- 内容（Markdown）
    cover TEXT,                       -- 封面图片
    category_id INTEGER,              -- 分类ID
    cost_price REAL DEFAULT 0,        -- 成本价
    sell_price REAL DEFAULT 0,        -- 售价
    is_public INTEGER DEFAULT 1,      -- 是否公开
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP  -- 创建时间
);
```

### categories 表（分类）

```sql
CREATE TABLE categories (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL                -- 分类名称
);
```

### admin 表（管理员）

```sql
CREATE TABLE admin (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT,                    -- 用户名
    password TEXT                     -- 密码（加密）
);
```

### pages 表（页面）

```sql
CREATE TABLE pages (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,              -- 标题
    slug TEXT NOT NULL UNIQUE,        -- URL别名
    content TEXT NOT NULL,            -- 内容（Markdown）
    is_public INTEGER DEFAULT 1,      -- 是否公开
    sort_order INTEGER DEFAULT 0,     -- 排序
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,  -- 创建时间
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP   -- 更新时间
);
```

### settings 表（设置）

```sql
CREATE TABLE settings (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    key TEXT NOT NULL UNIQUE,         -- 键
    value TEXT,                       -- 值
    description TEXT,                 -- 描述
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,  -- 创建时间
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP   -- 更新时间
);
```

## 核心函数

### 获取网站设置

```php
// config.php
function getSiteSetting($key, $default = '') {
    try {
        $db = new PDO('sqlite:' . DB_PATH);
        $table_exists = $db->query("SELECT name FROM sqlite_master WHERE type='table' AND name='settings'")->fetch();
        if ($table_exists) {
            $stmt = $db->prepare("SELECT value FROM settings WHERE key = ?");
            $stmt->execute([$key]);
            $result = $stmt->fetchColumn();
            return $result !== false ? $result : $default;
        }
    } catch (Exception $e) {
        // 返回默认值
    }
    return $default;
}
```

```php

    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
)
");
echo "✓ 表创建成功！\n";
?>
```

## API开发

### 创建API端点

创建 `api/recipes.php`：

```php
<?php
header('Content-Type: application/json');

$db = new PDO('sqlite:../data/data.db');

// 获取所有菜谱
if ($_SERVER['REQUEST_METHOD'] === 'GET') {
    $recipes = $db->query("SELECT * FROM recipes WHERE is_public=1")->fetchAll(PDO::FETCH_ASSOC);
    echo json_encode([
        'success' => true,
        'data' => $recipes
    ]);
}

// 创建菜谱
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $data = json_decode(file_get_contents('php://input'), true);
    $stmt = $db->prepare("INSERT INTO recipes (title, content) VALUES (?, ?)");
    $stmt->execute([$data['title'], $data['content']]);
    echo json_encode([
        'success' => true,
        'id' => $db->lastInsertId()
    ]);
}
?>
```
