## 安全建议

### 1. 删除安装文件
安装成功后，建议删除 `install.php` 文件：
```bash
rm install.php
```

### 2. 修改默认密码
登录后台后立即修改管理员密码：
- 后台 → 修改密码
- 设置强密码（至少8位，包含大小写字母、数字、特殊字符）

### 3. 设置文件权限
```bash
chmod 755 data/
chmod 644 data/data.db
chmod 755 uploads/
```

### 4. 配置防火墙
如果使用云服务器，配置防火墙规则，只开放必要的端口。

## 常见问题

### Q: 安装后如何删除 install.php？
A: 可以通过FTP、SSH或文件管理器删除该文件。

### Q: 忘记管理员密码怎么办？
A: 可以通过数据库工具重置密码，或删除数据库重新安装。

### Q: 安装失败怎么办？
A: 检查以下几点：
- PHP版本是否满足要求（7.4+）
- PDO SQLite扩展是否已安装
- data 目录是否有写入权限
- 查看错误信息，根据提示解决

### Q: 可以自定义默认数据吗？
A: 可以修改 `install.php` 中的默认数据部分。
