# 系统设置说明

本文档介绍商用菜谱库的系统设置和配置选项。

---

## 网站设置

### 基本设置

#### 网站标题
- **说明**：显示在浏览器标签页和搜索结果中
- **建议**：50-60字符以内，包含主要关键词
- **示例**：商用菜谱库 - 专业美食菜谱管理系统

#### 网站副标题
- **说明**：显示在网站标题下方，简短说明网站定位
- **建议**：20-30字符
- **示例**：专业的商用菜谱管理系统

#### 网站口号 (Slogan)
- **说明**：品牌宣传语，吸引用户
- **建议**：简短有力，易于记忆
- **示例**：让美食触手可及

### Meta 标签设置

#### Meta Description（网站描述）
- **说明**：显示在搜索结果摘要中，影响点击率
- **建议**：150-160字符，包含2-3个关键词
- **示例**：专业的商用菜谱管理系统，提供海量美食菜谱资源，支持分类管理、在线编辑、图片上传等功能，助力餐饮企业高效管理菜谱。

#### Meta Keywords（网站关键词）
- **说明**：帮助搜索引擎理解网站内容
- **建议**：5-10个关键词，用逗号分隔
- **示例**：菜谱,美食,烹饪,食谱,商用菜谱,餐饮管理,菜谱系统

#### Meta Author（网站作者）
- **说明**：网站所有者或管理者名称
- **示例**：商用菜谱库

### GEO 信息设置

#### 地理区域代码 (geo.region)
- **说明**：ISO 3166-1 国家代码
- **格式**：两位字母代码
- **示例**：CN（中国）、US（美国）、JP（日本）

#### 地理位置名称 (geo.placename)
- **说明**：具体城市或地区名称
- **格式**：国家,城市
- **示例**：中国,北京

#### 地理坐标 (geo.position)
- **说明**：精确的地理坐标（可选）
- **格式**：纬度;经度
- **示例**：39.9042;116.4074（北京）

## 系统设置

### 管理目录自定义

#### 功能说明
- 可以自定义管理后台的目录名称
- 增强系统安全性，防止恶意访问
- 修改后需要使用新的URL访问后台

#### 使用方法
1. 登录管理后台
2. 点击"系统设置"
3. 在"安全设置"区域输入新的目录名
4. 点击"重命名目录"按钮
5. 系统自动重命名并跳转到新地址

⚠️ **注意**：
- 目录名只能包含字母、数字、下划线
- 修改后请记住新的后台地址
- 建议使用难以猜测的名称

### URL 重写设置

#### 功能说明
- 启用伪静态，美化URL地址
- 需要服务器支持URL重写
- 支持Apache和Nginx

#### Apache 配置

1. 确保启用了 mod_rewrite 模块
2. 在后台"系统设置"中启用URL重写
3. 系统自动创建 .htaccess 文件

**手动配置：**
```apache
RewriteEngine On
RewriteBase /

# 菜谱详情页
RewriteRule ^recipe/([0-9]+)\.html$ recipe.php?t=$1 [L]

# 自定义页面
RewriteRule ^page/([a-z0-9-]+)\.html$ page.php?slug=$1 [L]

# 分类页面
RewriteRule ^category/([0-9]+)\.html$ index.php?cat=$1 [L]
```

#### Nginx 配置

在 nginx.conf 或站点配置文件中添加：

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
    
    # 菜谱详情页
    rewrite ^/recipe/([0-9]+)\.html$ /recipe.php?t=$1 last;
    
    # 自定义页面
    rewrite ^/page/([a-z0-9-]+)\.html$ /page.php?slug=$1 last;
    
    # 分类页面
    rewrite ^/category/([0-9]+)\.html$ /index.php?cat=$1 last;
}
```

#### 宝塔面板配置

1. 登录宝塔面板
2. 找到网站设置
3. 点击"伪静态"
4. 选择"自定义"
5. 粘贴Nginx配置规则
6. 保存配置

## 配置文件

### config.php

系统核心配置文件，包含：

```php
// 时区设置
date_default_timezone_set('Asia/Shanghai');

// 管理后台目录名称
define('ADMIN_DIR', 'admin');

// 数据库文件路径
define('DB_PATH', __DIR__ . '/data/data.db');

// 上传目录
define('UPLOAD_DIR', __DIR__ . '/uploads');

// 网站标题（默认值）
define('SITE_TITLE', '商用菜谱库');

// 每页显示数量
define('PER_PAGE', 12);

// 调试模式
define('DEBUG_MODE', false);
```

⚠️ **注意**：不建议直接修改此文件，请使用后台"网站设置"功能。

## SEO 优化建议

### 网站标题优化
- 长度控制在50-60字符以内
- 包含主要关键词
- 简洁明了，吸引点击
- 避免关键词堆砌

### 网站描述优化
- 长度控制在150-160字符
- 包含2-3个关键词
- 描述网站核心价值
- 吸引用户点击
- 使用行动号召语

### 关键词选择
- 选择与网站内容相关的关键词
- 包含核心关键词和长尾关键词
- 避免关键词堆砌
- 定期根据数据调整
- 关注竞争对手的关键词

### 地理信息优化
- 如果是本地业务，务必填写地理信息
- 有助于在本地搜索中获得更好排名
- 提升Google Maps等地图服务的可见性
- 使用准确的坐标信息

## 性能优化

### 数据库优化
- 定期执行数据库优化（后台 → 数据库优化）
- 建议每月优化一次
- 删除大量数据后立即优化

### 代码压缩
- 开发完成后执行代码压缩（后台 → 代码压缩）
- 可以减小文件体积20-40%
- 压缩前会自动创建备份

### 图片优化
- 上传前压缩图片
- 建议使用 JPG 格式
- 控制图片大小在 2MB 以内
- 使用适当的图片尺寸

---

## 备份策略

### 自动备份
- 代码压缩前自动创建备份
- 数据库优化前自动创建备份
- 备份文件保存在 backups 目录

### 手动备份
1. 后台 → 数据库优化
2. 点击"开始优化"
3. 下载备份文件到本地

### 备份建议
- 每周备份一次数据库
- 重要操作前先备份
- 保留至少3个历史备份
- 定期下载备份到本地

## 安全设置

### 修改管理员密码
1. 后台 → 修改密码
2. 输入旧密码和新密码
3. 密码要求：至少8位，包含大小写字母、数字

### 自定义管理目录
1. 后台 → 系统设置
2. 输入新的目录名称
3. 点击"重命名目录"

### 删除安装文件
安装完成后，删除 install.php 文件：
```bash
rm install.php
```

### 设置文件权限
```bash
chmod 755 data/
chmod 644 data/data.db
chmod 755 uploads/
chmod 755 backups/
```
