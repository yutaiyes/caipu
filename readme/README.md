- ✅ 分类管理
- ✅ 成本和售价管理

### 网站管理
- ✅ 自定义网站标题、副标题、口号
- ✅ SEO优化（描述、关键词、地理信息）

- ✅ 数据库优化
- ✅ 备份和恢复
- ✅ 安全设置
- ✅ 文档中心

## 🔧 系统要求

- PHP 7.4 或更高版本
- SQLite 3
- Web服务器（Apache/Nginx）
- 推荐：PHP扩展 pdo, pdo_sqlite, zip, mbstring, json

## 🎯 快速操作

### 安装系统
```bash
1. 上传文件到服务器
2. 访问 http://your-domain.com/install.php
3. 按照向导完成安装
```

### 登录后台
```
URL: http://your-domain.com/admin/
默认账号: admin
默认密码: 123456
```

### 修改密码
登录后台 → 个人资料 → 修改密码

## 📂 文件结构

```
项目根目录/
├── admin/              # 后台管理
├── assets/             # 静态资源
│   ├── css/           # 样式文件
│   └── js/            # 脚本文件
├── data/              # 数据库文件
├── includes/          # 公共文件
│   ├── header.php     # 公共头部
│   └── footer.php     # 公共底部
├── libs/              # 第三方库
├── readme/            # 文档目录
├── uploads/           # 上传文件
├── config.php         # 配置文件
├── index.php          # 首页
├── recipe.php         # 菜谱详情
└── page.php           # 自定义页面
```
