# 常见问题 (FAQ)

本文档收集了用户最常问的问题和解答。

---

## 安装相关

### Q1: 系统要求是什么？

**A:** 
- PHP 7.4 或更高版本
- PDO SQLite 扩展
- ZipArchive 扩展（用于备份功能）
- data 和 uploads 目录需要可写权限

### Q2: 如何安装系统？

**A:** 
1. 上传所有文件到服务器
2. 访问网站首页，自动跳转到安装页面
3. 点击"开始安装"按钮
4. 安装完成后，选择进入首页或管理后台

### Q3: 安装后需要做什么？

**A:** 
1. 删除 install.php 文件
2. 修改默认管理员密码（admin / 123456）
3. 配置网站设置
4. 添加菜谱内容

## 登录相关

### Q4: 默认管理员账号是什么？

**A:** 
- 用户名：admin
- 密码：123456

⚠️ 登录后请立即修改密码！

### Q5: 忘记管理员密码怎么办？

**A:** 
方法1：通过数据库重置
```bash
sqlite3 data/data.db
UPDATE admin SET password = '$2y$10$92IXUNpkjO0rOQ5byMi.Ye4oKoEa3Ro9llC/.og/at2.uheWG/igi' WHERE username = 'admin';
.quit
```

方法2：删除数据库重新安装

### Q6: 为什么无法登录后台？

**A:** 
可能原因：
- 密码输入错误
- Cookie被禁用
- Session未启动
- 浏览器缓存问题

解决方案：
- 清除浏览器缓存和Cookie
- 检查浏览器是否允许Cookie
- 尝试使用无痕模式

## 功能使用

### Q7: 如何添加菜谱？

**A:** 
1. 登录管理后台
2. 点击"新增菜谱"
3. 填写标题、描述、选择分类
4. 使用Markdown编辑器编写内容
5. 上传封面图片（可选）
6. 保存并发布

### Q8: 如何使用Markdown？

**A:** 
基本语法：
```markdown
# 一级标题
## 二级标题
**粗体** *斜体*
- 列表项
[链接](http://example.com)
![图片](http://example.com/image.jpg)
```

### Q9: 如何上传图片？

**A:** 
1. 在菜谱编辑页面
2. 点击"选择文件"按钮
3. 选择图片文件（jpg, png, gif）
4. 系统自动上传并显示预览

### Q10: 如何创建自定义页面？

**A:** 
1. 点击"页面管理"
2. 点击"新增页面"
3. 填写标题和URL别名
4. 使用Markdown编写内容
5. 设置排序和公开状态
6. 保存页面

## 设置相关

### Q11: 如何修改网站标题？

**A:** 
1. 登录管理后台

3. 修改网站标题、副标题、口号

## 高级功能

### Q14: 代码压缩安全吗？

**A:** 
是的，100%安全。系统使用PHP官方的 `token_get_all()` 函数，只删除注释和空白，不修改任何代码逻辑。压缩前会自动创建备份。

### Q15: 如何恢复压缩的代码？

**A:** 
1. 后台 → 代码压缩
2. 在"备份管理"区域找到备份文件
3. 点击"恢复"按钮
4. 确认恢复操作

### Q16: 数据库优化有什么用？

**A:** 
数据库优化可以：
- 回收删除记录后的空白空间
- 整理数据碎片
- 优化索引结构
- 提升查询效率
- 减小文件体积

### Q17: 多久优化一次数据库？

**A:** 
建议：
- 定期优化：每月一次
- 删除大量数据后立即优化
- 碎片率超过10%时优化
- 查询速度变慢时优化

## 备份相关

### Q18: 如何备份数据？

**A:** 
方法1：通过后台
1. 后台 → 数据库优化
2. 点击"开始优化"（自动创建备份）
3. 下载备份文件

方法2：手动备份
```bash
cp data/data.db backups/manual_backup_$(date +%Y%m%d).db
```

### Q19: 如何恢复备份？

**A:** 
方法1：通过后台
1. 后台 → 数据库优化
2. 在"数据库备份"区域找到备份
3. 点击"恢复"按钮

方法2：手动恢复
```bash
cp backups/backup_20260118.db data/data.db
```

### Q20: 备份文件保存在哪里？

**A:** 
- 代码备份：backups/backup_*.zip
- 数据库备份：backups/database_backup_*.db

### Q21: 如何提升网站速度？

**A:** 
1. 执行数据库优化
2. 执行代码压缩
3. 启用OPcache
4. 启用Gzip压缩
5. 使用CDN加速

### Q22: 为什么页面加载慢？

**A:** 
可能原因：
- 数据库未优化
- 数据量过大
- 服务器性能不足
- 网络连接慢

解决方案：
- 执行数据库优化
- 清理旧数据
- 升级服务器配置
- 使用CDN

## 安全相关

### Q23: 如何提高系统安全性？

**A:** 
1. 修改默认管理员密码
2. 删除 install.php 文件
3. 自定义管理目录名称
4. 设置正确的文件权限

**A:** 
系统已内置防护：
- 5次失败后锁定15分钟
- 记录登录IP地址

- 使用强密码
- 自定义管理目录
- 启用防火墙

## 故障排除

### Q25: 网站显示500错误怎么办？

**A:** 
1. 查看错误日志
2. 检查文件权限
3. 检查PHP配置
4. 恢复备份

### Q26: 上传图片失败怎么办？

**A:** 
1. 检查uploads目录权限
2. 检查PHP上传限制
3. 检查文件类型和大小
4. 查看错误日志

### Q27: 数据库损坏怎么办？

**A:** 
1. 尝试修复：
```bash
sqlite3 data/data.db "PRAGMA integrity_check;"
```

2. 如果无法修复，恢复备份：
```bash
cp backups/backup_20260118.db data/data.db
```
