# 故障排除

本文档提供常见问题的解决方案。

---

## 安装问题

### 问题1：无法创建数据库

**症状：**
- 访问install.php时报错
- 提示"无法创建数据库"

**原因：**
- data目录不存在或无写入权限
- PDO SQLite扩展未安装

**解决方案：**
```bash
# 创建data目录
mkdir data

# 设置权限
chmod 755 data/

# 检查PDO SQLite扩展
php -m | grep pdo_sqlite
```

### 问题2：安装后无法访问

**症状：**
- 安装完成后访问首页报错
- 显示"数据库连接失败"

**原因：**
- 数据库文件路径错误
- 文件权限不正确

**解决方案：**
```bash
# 检查数据库文件
ls -la data/data.db

# 设置权限
chmod 644 data/data.db
```

## 登录问题

### 问题1：无法登录后台

**症状：**
- 输入正确的用户名密码后无法登录
- 页面刷新但未跳转

**原因：**
- Session未启动
- Cookie被禁用
- 浏览器缓存问题

**解决方案：**
1. 清除浏览器缓存和Cookie
2. 检查浏览器是否允许Cookie
3. 尝试使用无痕模式
4. 检查PHP session配置

### 问题2：忘记管理员密码

**症状：**
- 无法登录后台

**解决方案1：通过数据库重置**
```bash
# 使用SQLite命令行
sqlite3 data/data.db

# 重置密码为123456
UPDATE admin SET password = '$2y$10$92IXUNpkjO0rOQ5byMi.Ye4oKoEa3Ro9llC/.og/at2.uheWG/igi' WHERE username = 'admin';

# 退出
.quit
```

**解决方案2：重新安装**
```bash
# 备份数据库
cp data/data.db data/data.db.backup

# 删除数据库
rm data/data.db

# 重新访问install.php安装
```

## 上传问题

### 问题1：无法上传图片

**症状：**
- 点击上传按钮无反应
- 上传后显示错误

**原因：**
- uploads目录无写入权限
- PHP上传限制太小
- 文件类型不支持

**解决方案：**
```bash
# 设置uploads目录权限
chmod 755 uploads/

# 检查PHP配置
php -i | grep upload_max_filesize
php -i | grep post_max_size

# 修改php.ini
upload_max_filesize = 10M
post_max_size = 10M
```

### 问题2：上传的图片不显示

**症状：**
- 图片上传成功但前端不显示
- 显示图片链接错误

**原因：**
- 图片路径错误
- 文件权限问题

**解决方案：**
```bash
# 检查图片文件
ls -la uploads/

# 设置权限
chmod 644 uploads/*.jpg
chmod 644 uploads/*.png
```

## 性能问题

### 问题1：页面加载缓慢

**症状：**
- 首页加载时间超过5秒
- 数据库查询慢

**原因：**
- 数据库未优化
- 数据量过大
- 服务器性能不足

**解决方案：**
1. 执行数据库优化
```bash
# 后台 → 数据库优化 → 开始优化
```

2. 启用OPcache
```ini
# php.ini
opcache.enable=1
opcache.memory_consumption=128
opcache.max_accelerated_files=10000
```

3. 启用Gzip压缩
```apache
# Apache .htaccess
<IfModule mod_deflate.c>
    AddOutputFilterByType DEFLATE text/html text/plain text/xml text/css text/javascript application/javascript
</IfModule>
```

### 问题2：数据库文件过大

**症状：**
- data.db文件超过100MB
- 查询速度变慢

**原因：**
- 数据碎片过多
- 未定期优化

**解决方案：**
```bash
# 1. 备份数据库
cp data/data.db backups/backup_$(date +%Y%m%d).db

# 2. 执行优化
# 后台 → 数据库优化 → 开始优化

# 3. 检查文件大小
ls -lh data/data.db
```

## 功能问题

### 问题1：代码压缩后网站无法访问

**症状：**
- 执行代码压缩后网站报错
- 显示语法错误

**原因：**
- 压缩规则有问题
- 某些代码被错误处理

**解决方案：**
```bash
# 立即恢复备份
# 后台 → 代码压缩 → 备份管理 → 恢复

# 或手动恢复
cd backups
unzip backup_20260118.zip -d ../
```

### 问题2：数据库优化失败

**症状：**
- 点击优化按钮后报错
- 提示"数据库锁定"

**原因：**
- 数据库正在被其他进程使用
- 磁盘空间不足

**解决方案：**
1. 关闭所有数据库连接
2. 检查磁盘空间
```bash
df -h
```
3. 稍后重试

## 权限问题

### 问题1：无法创建备份

**症状：**
- 执行压缩或优化时报错
- 提示"无法创建备份"

**原因：**
- backups目录无写入权限
- 磁盘空间不足

**解决方案：**
```bash
# 创建backups目录
mkdir backups

# 设置权限
chmod 755 backups/

# 检查磁盘空间
df -h
```

### 问题2：无法写入数据库

**症状：**
- 添加或编辑菜谱时报错
- 提示"数据库只读"

**原因：**
- 数据库文件权限不正确
- data目录权限不正确

**解决方案：**
```bash
# 设置权限
chmod 644 data/data.db
chmod 755 data/

# 设置所有者（Linux）
chown www-data:www-data data/data.db
```

## 错误代码

### HTTP 500 错误

**原因：**
- PHP语法错误
- 服务器配置错误
- 权限问题

**解决方案：**
1. 查看错误日志
```bash
# Apache
tail -f /var/log/apache2/error.log

# Nginx
tail -f /var/log/nginx/error.log
```

2. 检查PHP错误
```bash
tail -f /var/log/php_errors.log
```

3. 启用错误显示（仅开发环境）
```php
// config.php
ini_set('display_errors', 1);
error_reporting(E_ALL);
```

### HTTP 404 错误

**原因：**
- 文件不存在
- URL重写规则错误
- 路径配置错误

**解决方案：**
1. 检查文件是否存在
2. 检查.htaccess配置
3. 检查Nginx配置

### HTTP 403 错误

**原因：**
- 文件权限不正确
- 目录索引被禁用
- IP被封禁

**解决方案：**
```bash
# 设置正确的权限
chmod 644 *.php
chmod 755 */
```

## 数据库问题

### 问题1：数据库损坏

**症状：**
- 访问网站时报错
- 提示"数据库文件损坏"

**解决方案：**
```bash
# 1. 尝试修复
sqlite3 data/data.db "PRAGMA integrity_check;"

# 2. 如果无法修复，恢复备份
cp backups/backup_20260118.db data/data.db

# 3. 重新优化
# 后台 → 数据库优化
```

### 问题2：数据丢失

**症状：**
- 菜谱或分类突然消失
- 数据不完整

**解决方案：**
```bash
# 恢复最近的备份
cp backups/backup_20260118.db data/data.db

# 或恢复数据库备份
cp backups/database_backup_20260118.db data/data.db
```

## 浏览器兼容性

### 问题1：IE浏览器显示异常

**原因：**
- IE不支持某些CSS3特性
- IE不支持某些JavaScript特性

**解决方案：**
- 建议使用现代浏览器（Chrome, Firefox, Edge, Safari）
- 升级到IE11或更高版本

### 问题2：移动端显示问题

**原因：**
- 响应式设计未生效
- 视口设置错误

**解决方案：**
- 清除浏览器缓存
- 检查viewport meta标签
- 使用Chrome开发者工具测试

## 调试技巧

### 1. 启用调试模式

```php
// config.php
define('DEBUG_MODE', true);
ini_set('display_errors', 1);
error_reporting(E_ALL);
```

### 2. 查看PHP信息

创建 `phpinfo.php` 文件：
```php
<?php
phpinfo();
?>
```

访问 `http://your-domain.com/phpinfo.php`

⚠️ **注意**：查看完后立即删除此文件！

### 3. 使用浏览器开发者工具

- **Chrome**：F12 或 Ctrl+Shift+I
- **Firefox**：F12 或 Ctrl+Shift+I
- **Safari**：Cmd+Option+I

查看：
- Console（控制台错误）
- Network（网络请求）
- Elements（页面元素）
