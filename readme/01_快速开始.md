# 快速开始指南

## 欢迎使用商用菜谱库

商用菜谱库是一个专业的菜谱管理系统，支持Markdown编辑、图片上传、分类管理等功能。

---

## 系统要求

- **PHP**：7.4 或更高版本
- **扩展**：PDO SQLite、ZipArchive
- **权限**：data 和 uploads 目录需要可写权限

---

## 快速安装

### 方法1：自动安装（推荐）

1. 上传所有文件到服务器
2. 访问网站首页，系统自动跳转到安装页面
3. 点击"开始安装"按钮
4. 安装完成后，选择进入首页或管理后台

### 方法2：手动安装

```bash
# 1. 上传文件到服务器
# 2. 设置目录权限
chmod 755 data/
chmod 755 uploads/
chmod 755 backups/

# 3. 访问安装页面
http://your-domain.com/install.php

# 4. 安装完成后删除安装文件
rm install.php
```

## 首次配置

### 1. 修改管理员密码

1. 登录管理后台
2. 点击左侧菜单"修改密码"
3. 输入旧密码和新密码
4. 保存修改

### 2. 配置网站设置

1. 点击左侧菜单"网站设置"
2. 填写网站标题、副标题、口号
3. 配置Meta标签（描述、关键词、作者）
4. 配置GEO信息（区域代码、位置名称、坐标）
5. 保存设置

### 3. 添加菜谱分类

1. 点击左侧菜单"分类管理"
2. 添加或编辑分类
3. 系统已预置8个中国菜系分类

### 4. 添加第一个菜谱

1. 点击左侧菜单"新增菜谱"
2. 填写菜谱标题、描述
3. 选择分类
4. 使用Markdown编辑器编写内容
5. 上传封面图片（可选）
6. 设置成本价和售价（可选）
7. 保存并发布

## 常见问题

### Q: 安装后无法访问？
A: 检查以下几点：
- PHP版本是否满足要求（7.4+）
- data 目录是否有写入权限
- PDO SQLite扩展是否已安装

### Q: 忘记管理员密码？
A: 可以通过以下方式重置：
1. 使用数据库工具修改 admin 表
2. 或删除数据库重新安装

### Q: 如何备份数据？
A: 两种方式：
1. 后台 → 数据库优化 → 下载备份
2. 直接复制 data/data.db 文件

### Q: 如何迁移网站？
A: 步骤：
1. 复制所有文件到新服务器
2. 复制 data/data.db 数据库文件
3. 设置目录权限
4. 访问新网站地址
