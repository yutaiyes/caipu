# 安全指南

本文档介绍商用菜谱库的安全设置和最佳实践。

---

## 基本安全措施

### 1. 修改默认密码

⚠️ **最重要**：安装后立即修改默认管理员密码！

**步骤：**
1. 登录管理后台（admin / 123456）
2. 点击"修改密码"
3. 输入旧密码：123456
4. 输入新密码（至少8位）
5. 确认新密码
6. 保存修改

**密码要求：**
- 至少8个字符
- 包含大写字母
- 包含小写字母
- 包含数字
- 建议包含特殊字符

**示例强密码：**
- `MyP@ssw0rd2026`
- `Secure#Recipe123`
- `Admin$2026!Safe`

### 2. 删除安装文件

安装完成后，立即删除 `install.php` 文件：

```bash
rm install.php
```

或通过FTP/文件管理器删除。

### 3. 自定义管理目录

将默认的 `admin` 目录改为难以猜测的名称：

**步骤：**
1. 登录管理后台
2. 点击"系统设置"
3. 在"安全设置"区域输入新目录名
4. 点击"重命名目录"
5. 系统自动跳转到新地址

**建议名称：**
- `manage_2026`
- `backend_secure`
- `control_panel`
- 使用随机字符串

⚠️ **注意**：修改后请记住新的后台地址！

## 文件权限设置

### Linux/Unix 系统

```bash
# 设置目录权限
chmod 755 data/
chmod 755 uploads/
chmod 755 backups/

# 设置文件权限
chmod 644 data/data.db
chmod 644 config.php
chmod 644 index.php

# 设置所有者
chown www-data:www-data data/
chown www-data:www-data uploads/
chown www-data:www-data backups/
```

### Windows 系统

1. 右键点击目录
2. 选择"属性"
3. 点击"安全"选项卡
4. 设置适当的权限

### 权限说明

| 目录/文件 | 权限 | 说明 |
|-----------|------|------|
| data/     | 755  | 数据库目录 |
| uploads/  | 755  | 上传文件目录 |
| backups/  | 755  | 备份文件目录 |
| data.db   | 644  | 数据库文件 |
| *.php     | 644  | PHP文件 |

## 数据库安全

### 1. 定期备份

**自动备份：**
- 代码压缩前自动备份
- 数据库优化前自动备份

**手动备份：**
```bash
# 复制数据库文件
cp data/data.db backups/manual_backup_$(date +%Y%m%d).db

# 下载到本地
# 通过FTP或后台下载
```

**备份策略：**
- 每天备份一次
- 保留最近7天的备份
- 每周备份一次到本地
- 重要操作前先备份

### 2. 数据库加密

SQLite数据库可以使用加密扩展：

```php
// 使用SQLCipher加密数据库
$db = new PDO('sqlite:data/data.db');
$db->exec("PRAGMA key = 'your-encryption-key'");
```

⚠️ **注意**：需要安装SQLCipher扩展。

### 3. 防止SQL注入

系统已使用PDO预处理语句防止SQL注入：

```php
// 安全的查询方式
$stmt = $db->prepare("SELECT * FROM recipes WHERE id = ?");
$stmt->execute([$id]);

// 不安全的方式（已避免）
// $db->query("SELECT * FROM recipes WHERE id = $id");
```

## 登录安全

### 1. 会话安全

系统已实现会话安全机制：
- 会话超时（30分钟无操作）
- 会话固定攻击防护
- 会话劫持防护

### 2. 登录限制

系统已实现登录尝试限制：
- 5次失败后锁定15分钟
- 记录登录IP地址
- 记录登录时间

### 3. 强制HTTPS

建议启用HTTPS加密传输：

**Apache配置：**
```apache
# 强制HTTPS
RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
```

**Nginx配置：**
```nginx
# 强制HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}
```

## 文件上传安全

### 1. 文件类型限制

系统已限制上传文件类型：
- 允许：jpg, jpeg, png, gif
- 禁止：php, exe, sh, bat

### 2. 文件大小限制

**PHP配置：**
```ini
upload_max_filesize = 2M
post_max_size = 2M
```

### 3. 文件名处理

系统自动处理上传文件名：
- 使用时间戳前缀
- 保留原文件扩展名
- 避免特殊字符

### 4. 上传目录保护

**Apache配置：**
```apache
# uploads/.htaccess
<Files *.php>
    deny from all
</Files>
```

**Nginx配置：**
```nginx
location ~* ^/uploads/.*\.php$ {
    deny all;
}
```

## XSS 防护

### 1. 输出转义

系统已对所有输出进行转义：

```php
// 安全的输出方式
echo htmlspecialchars($user_input);

// 不安全的方式（已避免）
// echo $user_input;
```

### 2. Content Security Policy

建议添加CSP头：

```php
header("Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline' cdnjs.cloudflare.com; style-src 'self' 'unsafe-inline' cdnjs.cloudflare.com;");
```

## CSRF 防护

### 1. Token验证

建议在表单中添加CSRF Token：

```php
// 生成Token
$_SESSION['csrf_token'] = bin2hex(random_bytes(32));

// 验证Token
if ($_POST['csrf_token'] !== $_SESSION['csrf_token']) {
    die('CSRF token验证失败');
}
```

### 2. Referer检查

```php
// 检查Referer
$referer = $_SERVER['HTTP_REFERER'] ?? '';
if (strpos($referer, $_SERVER['HTTP_HOST']) === false) {
    die('非法请求');
}
```

## 服务器安全

### 1. 隐藏PHP版本

**php.ini配置：**
```ini
expose_php = Off
```

### 2. 禁用危险函数

**php.ini配置：**
```ini
disable_functions = exec,passthru,shell_exec,system,proc_open,popen,curl_exec,curl_multi_exec,parse_ini_file,show_source
```

### 3. 错误日志

**php.ini配置：**
```ini
display_errors = Off
log_errors = On
error_log = /var/log/php_errors.log
```

### 4. 防火墙设置

**UFW（Ubuntu）：**
```bash
# 允许HTTP和HTTPS
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 启用防火墙
sudo ufw enable
```

**Firewalld（CentOS）：**
```bash
# 允许HTTP和HTTPS
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload
```
