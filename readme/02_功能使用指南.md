# 功能使用指南

本文档详细介绍商用菜谱库的各项功能使用方法。

---

## 菜谱管理

### 添加菜谱

1. 登录管理后台
2. 点击"新增菜谱"
3. 填写基本信息：
   - **标题**：菜谱名称（必填）
   - **描述**：简短介绍（可选）
   - **分类**：选择所属分类
   - **封面图片**：上传菜谱封面
   - **成本价**：制作成本（可选）
   - **售价**：销售价格（可选）
   - **是否公开**：控制前端显示

4. 编写内容：
   - 使用Markdown编辑器
   - 支持标题、列表、表格、代码块等
   - 可以插入图片链接
   - 支持可视化和源码模式切换

5. 保存并发布

### 编辑菜谱

1. 点击"菜谱列表"
2. 找到要编辑的菜谱
3. 点击"编辑"按钮
4. 修改内容后保存

### 删除菜谱

1. 在菜谱列表中找到要删除的菜谱
2. 点击"删除"按钮
3. 确认删除操作

⚠️ **注意**：删除操作不可恢复，请谨慎操作！

---

## 分类管理

### 添加分类

1. 点击"分类管理"
2. 在输入框中输入分类名称
3. 点击"添加分类"按钮

### 编辑分类

1. 在分类列表中找到要编辑的分类
2. 点击"编辑"按钮
3. 修改分类名称
4. 保存修改

### 删除分类

1. 在分类列表中找到要删除的分类
2. 点击"删除"按钮
3. 确认删除

⚠️ **注意**：删除分类不会删除该分类下的菜谱，菜谱会变为"未分类"状态。

---

## 页面管理

### 添加自定义页面

1. 点击"页面管理"
2. 点击"新增页面"
3. 填写信息：
   - **标题**：页面标题
   - **URL别名**：页面访问地址（如：about）
   - **内容**：使用Markdown编写
   - **排序**：控制导航栏显示顺序
   - **是否公开**：控制前端显示

4. 保存页面

### 访问自定义页面

前端访问地址：`http://your-domain.com/page.php?slug=about`

### 编辑页面

1. 在页面列表中找到要编辑的页面
2. 点击"编辑"按钮
3. 修改内容后保存

## Markdown 使用技巧

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 列表

```markdown
- 无序列表项1
- 无序列表项2

1. 有序列表项1
2. 有序列表项2
```

### 粗体和斜体

```markdown
**粗体文本**
*斜体文本*
***粗斜体文本***
```

### 链接和图片

```markdown
[链接文本](http://example.com)
![图片描述](http://example.com/image.jpg)
```

### 表格

```markdown
| 材料 | 用量 | 备注 |
|------|------|------|
| 鸡蛋 | 2个  | 新鲜 |
| 盐   | 适量 | -    |
```

### 代码块

```markdown
\`\`\`
代码内容
\`\`\`
```

## 图片上传

### 上传封面图片

1. 在菜谱编辑页面
2. 点击"选择文件"按钮
3. 选择图片文件（支持 jpg, png, gif）
4. 系统自动上传并显示预览

### 图片要求

- **格式**：JPG, PNG, GIF
- **大小**：建议不超过 2MB
- **尺寸**：建议 800x600 像素

### 图片存储

- 上传的图片保存在 `uploads/` 目录
- 文件名格式：`时间戳_原文件名`
- 可以通过FTP管理上传的图片

## 前端浏览

### 首页

- 显示所有公开的菜谱
- 支持按分类筛选
- 显示统计信息（菜谱数量、分类数量）
- 响应式设计，支持移动端

### 菜谱详情页

- 显示菜谱完整内容
- 显示成本价和售价
- 显示相关菜谱推荐
- 支持返回首页

### 自定义页面

- 显示Markdown格式的页面内容
- 支持导航栏访问
- 响应式设计

---

## 搜索和筛选

### 按分类筛选

1. 在首页点击分类标签
2. 系统自动筛选该分类下的菜谱
3. 点击"全部"返回所有菜谱

### 菜谱排序

- 默认按创建时间倒序排列（最新的在前）
- 可以在后台菜谱列表中查看所有菜谱

---

## 数据统计

### 仪表板

登录后台后，仪表板显示：
- 菜谱总数
- 分类总数
- 公开菜谱数量
- 最近添加的菜谱

### 查看统计

1. 点击"仪表板"
2. 查看各项统计数据
3. 快速访问常用功能

## 常见操作

### 批量操作

目前系统不支持批量操作，需要逐个处理。

### 导入导出

- **导出**：后台 → 数据库优化 → 下载备份
- **导入**：复制数据库文件到 data 目录

### 数据备份

建议定期备份：
1. 后台 → 数据库优化
2. 点击"开始优化"（自动创建备份）
3. 下载备份文件到本地
