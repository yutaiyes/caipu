## 升级指南

### 从v1.0.0升级到v1.5.0

1. **备份数据**
```bash
cp data/data.db backups/backup_before_upgrade.db
```

2. **上传新文件**
- 覆盖所有PHP文件
- 保留data目录
- 保留uploads目录

3. **运行升级脚本**
```bash
# 访问浏览器
http://your-domain.com/upgrade_settings.php
```

4. **清除缓存**
- 清除浏览器缓存
- 清除服务器缓存

5. **测试功能**
- 登录后台
- 测试所有功能
- 检查前端显示
