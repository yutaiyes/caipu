# 伪静态规则说明文档

## 概述
本系统使用Apache的mod_rewrite模块实现URL伪静态，提供更美观和SEO友好的URL格式。

## 当前版本：v2.0
- 支持12位固定长度编码的菜谱详情页
- 兼容旧版本的数字ID格式
- 完整的分类和页面伪静态支持

## URL格式对照表

### 菜谱详情页
| 原始格式 | 伪静态格式 | 说明 | 示例 |
|---------|-----------|------|------|
| `recipe.php?base=540000000001` | `540000000001.html` | 12位编码格式（推荐） | `540000000001.html` |
| `recipe.php?id=1` | `recipe/1.html` | 传统数字ID格式 | `recipe/1.html` |

### 分类页面
| 原始格式 | 伪静态格式 | 说明 | 示例 |
|---------|-----------|------|------|
| `index.php?cat=1` | `category/1.html` | 分类页面 | `category/1.html` |

### 自定义页面
| 原始格式 | 伪静态格式 | 说明 | 示例 |
|---------|-----------|------|------|
| `page.php?slug=about` | `page/about.html` | 自定义页面 | `page/about.html` |

## 12位编码规则

### 编码算法
1. **进制转换**：将10进制ID转换为36进制（0-9 + A-Z）
2. **前缀生成**：基于ID的MD5哈希生成2位前缀
3. **长度填充**：填充到12位固定长度

### 编码示例
| ID | 36进制 | 前缀 | 12位编码 | URL |
|----|--------|------|----------|-----|
| 1 | 1 | 54 | 540000000001 | `540000000001.html` |
| 12 | C | 94 | 94000000000C | `94000000000C.html` |
| 999 | RR | A0 | A000000000RR | `A000000000RR.html` |
| 99999 | 255R | E6 | E6255R000000 | `E6255R000000.html` |

## Nginx 伪静态规则

如果您使用的是 Nginx 服务器（如宝塔面板），请使用以下规则：

```nginx
location / {
    if (!-e $request_filename){
        rewrite "^/([0-9B-Zb-z][a-zA-Z0-9]{11})\.html$" /recipe.php?base=$1 last;
        rewrite ^/recipe/([0-9]+)\.html$ /recipe.php?id=$1 last;
        rewrite ^/category/([0-9]+)\.html$ /index.php?cat=$1 last;
        rewrite "^/([Aa][a-zA-Z0-9]{11})\.html$" /page.php?base=$1 last;
        rewrite ^/page/([a-zA-Z0-9_-]+)\.html$ /page.php?slug=$1 last;
        rewrite ^/index\.html$ /index.php last;
    }
}
```

> **注意**：在 Nginx 中，如果正则表达式包含 `{` 和 `}`，必须用双引号将整个正则表达式包围起来，否则会报错。

## .htaccess规则详解

### 核心规则
```apache
# 12位编码菜谱详情页
RewriteRule ^([0-9B-Zb-z][a-zA-Z0-9]{11})\.html$ recipe.php?base=$1 [L,QSA]

# 12位编码自定义页面
RewriteRule ^([Aa][a-zA-Z0-9]{11})\.html$ page.php?base=$1 [L,QSA]

# 兼容旧格式
RewriteRule ^recipe/([0-9]+)\.html$ recipe.php?id=$1 [L,QSA]
```

### 参数说明
- `^([0-9B-Zb-z][a-zA-Z0-9]{11})\.html$`：匹配12位编码（首位非A）
- `^([Aa][a-zA-Z0-9]{11})\.html$`：匹配12位页面编码（首位A）
- `$1`：第一个捕获组的内容
- `[L,QSA]`：标志说明
  - `L`：Last rule，停止处理后续规则
  - `QSA`：Query String Append，保留原有查询参数

## 兼容性说明

### 向后兼容
- 支持旧的数字ID格式：`recipe/1.html`
- 支持原始参数格式：`recipe.php?id=1`
- 所有格式都能正常访问

### 优先级
1. 12位编码格式优先（新格式）
2. 数字ID格式（兼容旧版）
3. 原始PHP参数格式（最后兼容）

## 管理后台集成

### 预览链接

## 测试方法

### 功能测试
1. 访问 `540000000001.html` 应该显示ID为1的菜谱
2. 访问 `recipe/1.html` 应该显示相同内容
3. 访问 `recipe.php?base=540000000001` 应该显示相同内容

### 锚点测试
1. 访问任意菜谱详情页
2. 点击"返回列表"
3. 应该跳转到 `index.php#recipe-ID` 并自动滚动到对应位置

## 故障排除

### 常见问题
1. **404错误**：检查mod_rewrite是否启用
2. **500错误**：检查.htaccess语法
3. **伪静态不生效**：检查Apache配置

### 调试方法
```apache
# 启用重写日志（调试用）
RewriteLog "/var/log/apache2/rewrite.log"
RewriteLogLevel 3
```
