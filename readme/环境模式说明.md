# 环境模式说明

## 概述

系统支持两种运行环境模式：**生产环境（Production）** 和 **开发环境（Development）**。您可以在后台的"网站设置"页面一键切换。

---

## 环境模式对比

### 生产环境 (Production)

**推荐用于：** 正式上线的网站

**特性：**
- ✅ **错误隐藏**：不显示PHP错误信息，保护系统安全
- ✅ **性能优化**：关闭调试功能，提升系统性能
- ✅ **日志记录**：错误将记录到 `data/error.log` 文件
- ✅ **安全性高**：不暴露敏感的系统信息
- ✅ **用户体验**：用户看到友好的错误提示而非技术细节

**适用场景：**
- 网站正式上线后
- 有真实用户访问时
- 需要保护系统安全时
- 追求最佳性能时

---

### 开发环境 (Development)

**推荐用于：** 开发和调试阶段

**特性：**
- 🔧 **错误显示**：显示详细的PHP错误信息
- 🔧 **调试信息**：显示SQL查询和系统调试信息
- 🔧 **快速定位**：帮助开发者快速发现和解决问题
- ⚠️ **安全风险**：可能暴露敏感信息
- ⚠️ **性能影响**：调试模式可能影响系统性能

**适用场景：**
- 本地开发环境
- 测试服务器
- 调试系统问题时
- 开发新功能时

---

## 如何切换环境模式

### 方法一：后台设置（推荐）

1. 登录管理后台
2. 进入 **网站设置** 页面
3. 找到 **系统环境设置** 部分
4. 在 **环境模式** 下拉菜单中选择：
   - `生产环境 (Production)` - 正式环境
   - `开发环境 (Development)` - 开发环境
5. 点击 **保存设置** 按钮
6. 刷新页面查看效果

### 方法二：数据库直接修改

如果无法访问后台，可以直接修改数据库：

```sql
-- 切换为生产环境
UPDATE settings SET value = 'production' WHERE key = 'environment_mode';

-- 切换为开发环境
UPDATE settings SET value = 'development' WHERE key = 'environment_mode';
```

## 技术细节

### 错误处理配置

**生产环境：**
```php
error_reporting(E_ALL);
ini_set('display_errors', '0');
ini_set('display_startup_errors', '0');
ini_set('log_errors', '1');
ini_set('error_log', __DIR__ . '/data/error.log');
```

**开发环境：**
```php
error_reporting(E_ALL);
ini_set('display_errors', '1');
ini_set('display_startup_errors', '1');
```

### 配置文件

环境模式配置在 `config.php` 中实现：

```php
// 获取环境模式
$environment_mode = getEnvironmentMode();
define('ENVIRONMENT_MODE', $environment_mode);

// 应用配置
if ($environment_mode === 'development') {
    // 开发环境配置
} else {
    // 生产环境配置
}
```

### 数据库存储

环境模式设置存储在 `settings` 表中：

| key | value | description |
|-----|-------|-------------|
| environment_mode | production 或 development | 环境模式：production或development |

## 最佳实践

### 1. 开发流程

```
本地开发 (Development)
    ↓
测试服务器 (Development)
    ↓
预发布环境 (Production)
    ↓
正式环境 (Production)
```

### 2. 切换时机

**切换为开发模式：**
- 需要调试问题时
- 开发新功能时
- 测试系统时
- 查看详细错误信息时

**切换为生产模式：**
- 网站正式上线前
- 有真实用户访问时
- 完成调试后
- 追求最佳性能时

### 3. 安全建议

- ⚠️ **永远不要**在生产环境使用开发模式
- ✅ 定期检查环境模式设置
- ✅ 上线前确认已切换为生产模式
- ✅ 开发完成后立即切换回生产模式
- ✅ 限制开发模式的访问权限

### 4. 错误日志

生产环境下，错误会记录到 `data/error.log`：

```bash
# 查看错误日志
tail -f data/error.log

# 清空错误日志
> data/error.log
```

## 常见问题

### Q1: 切换环境模式后需要重启服务器吗？

**A:** 不需要。切换后立即生效，刷新页面即可看到效果。

### Q2: 开发模式会影响性能吗？

**A:** 是的。开发模式会显示额外的调试信息，可能会略微影响性能。但影响通常很小，主要是为了安全考虑不建议在生产环境使用。

### Q3: 如何查看生产环境的错误？

**A:** 生产环境的错误会记录到 `data/error.log` 文件中。您可以通过FTP或SSH查看该文件。

### Q4: 忘记切换为生产模式怎么办？

**A:** 系统会在后台显示明显的警告提示。如果已经上线，请立即登录后台切换为生产模式。

### Q5: 可以为不同的用户设置不同的环境模式吗？

**A:** 不可以。环境模式是全局设置，影响整个系统。

### Q6: 开发模式会暴露哪些信息？

**A:** 开发模式可能暴露：
- PHP错误信息和堆栈跟踪
- 文件路径
- 数据库查询语句
- 系统配置信息

因此不建议在生产环境使用。

## 故障排除

### 问题1：切换后没有生效

**解决方案：**
1. 清除浏览器缓存
2. 刷新页面（Ctrl+F5）
3. 检查数据库中的设置是否已更新
4. 检查 `config.php` 文件权限

### 问题2：无法访问后台设置页面

**解决方案：**
1. 直接修改数据库（见上文"方法二"）
2. 检查文件权限
3. 查看 `data/error.log` 了解错误原因

### 问题3：生产环境看不到任何错误

**解决方案：**
这是正常的。生产环境会隐藏错误信息。如需查看错误：
1. 查看 `data/error.log` 文件
2. 或临时切换为开发模式
