## 使用示例

### 创建新页面

```php
<?php
require_once 'config.php';
$db = new PDO('sqlite:data/data.db');

// 设置页面特定变量
$page_title = '新页面标题';
$page_description = '页面描述';
$page_keywords = '关键词1,关键词2';

// 引入公共头部
require_once 'includes/header.php';
?>

<!-- 你的页面内容 -->
<div class="container py-5">
    <h1>页面内容</h1>
    <p>这是一个新页面...</p>
</div>

<?php require_once 'includes/footer.php'; ?>
```
