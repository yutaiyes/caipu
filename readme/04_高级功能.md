## 代码压缩

### 功能说明

代码压缩功能可以删除PHP代码中的注释和空白，减小文件体积，提升加载速度。

### 压缩规则

- ✅ 使用PHP官方 `token_get_all()` 函数（100%安全）
- ✅ 删除单行注释（// 和 #）
- ✅ 删除多行注释（/* */）
- ✅ 保留重要注释（@license, @copyright, @author）
- ✅ 删除空白行和多余空格
- ✅ 自动保护所有字符串内容
- ✅ 不修改任何代码逻辑

### 使用方法

1. 登录管理后台
2. 点击"代码压缩"
3. 阅读压缩说明和注意事项
4. 点击"开始压缩全站代码"
5. 确认警告对话框
6. 等待压缩完成
7. 查看压缩结果

### 压缩效果

**压缩前：**
```php
<?php
// 这是注释
function test() {
    // 获取数据
    $data = getData();
    
    // 返回结果
    return $data;
}
?>
```

**压缩后：**
```php
<?php
function test() {
$data = getData();
return $data;
}
?>
```

通常可以节省 20-40% 的文件体积。

### 备份管理

- 压缩前自动创建ZIP备份
- 备份文件保存在 backups 目录
- 可以随时恢复备份
- 支持下载备份到本地
- 支持删除旧备份

### 恢复备份

1. 在"备份管理"区域找到备份文件
2. 点击"恢复"按钮
3. 确认恢复操作
4. 系统自动恢复所有文件

### 注意事项

- 压缩后代码难以阅读和编辑
- 建议在开发完成后再压缩
- 压缩后请测试所有功能
- 如需修改代码，请先恢复备份
- 定期清理旧的备份文件

## 数据库优化

### 功能说明

数据库优化使用SQLite官方的VACUUM命令，可以：
- 回收删除记录后的空白空间
- 整理数据碎片
- 优化索引结构
- 提升查询效率

### 何时需要优化

- 删除了大量数据后
- 数据库碎片率超过10%
- 数据库文件异常增大
- 查询速度明显变慢
- 定期维护（建议每月一次）

### 使用方法

1. 登录管理后台
2. 点击"数据库优化"
3. 查看数据库信息和碎片率
4. 点击"开始优化数据库"
5. 确认优化操作
6. 等待优化完成
7. 查看优化结果

### 优化效果

- 减小文件体积
- 提升查询速度
- 优化索引
- 整理碎片

### 备份管理

- 优化前自动创建数据库备份
- 备份文件保存在 backups 目录
- 可以随时恢复备份
- 支持下载备份到本地

### 注意事项

- 优化期间数据库会被锁定
- 优化时间取决于数据库大小
- 建议在访问量较少时进行
- 需要足够的磁盘空间

## URL 时间戳

### 功能说明

菜谱URL使用时间戳而不是ID，增加安全性。

### URL 格式

- **新格式**：`recipe.php?t=1737177600`
- **旧格式**：`recipe.php?id=123`（仍然支持）

### 优点

- URL更难猜测
- 时间戳唯一
- 向后兼容
- 增加安全性

### 页面URL

页面URL保持slug格式不变：
- `page.php?slug=about`
- `page.php?slug=contact`

## 批量操作

### 导出数据

```bash
# 导出数据库
cp data/data.db backup_$(date +%Y%m%d).db

# 导出上传文件
tar -czf uploads_$(date +%Y%m%d).tar.gz uploads/
```

### 导入数据

```bash
# 导入数据库
cp backup_20260118.db data/data.db

# 导入上传文件
tar -xzf uploads_20260118.tar.gz
```

## API 接口

### 获取菜谱列表

```php
// 示例代码

$recipes = $db->query("SELECT * FROM recipes WHERE is_public=1")->fetchAll();
echo json_encode($recipes);
```

```php
$categories = $db->query("SELECT * FROM categories")->fetchAll();
```
