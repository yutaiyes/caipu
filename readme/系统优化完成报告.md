- 恢复所有文档链接为正确的 `docs.php?doc=文件名` 格式
- 锚点链接格式：`文件名#锚点`
- 保持与程序实现一致

### 修复文件

### 修复统计

## 6. 技术细节

### 返回顶部按钮实现

**HTML结构：**
```html
<button id="backToTop" class="back-to-top" title="返回顶部">
    <i class="fas fa-arrow-up"></i>
</button>
```

**CSS样式：**
```css
.back-to-top {
    position: fixed;
    bottom: 30px;
    right: 30px;
    width: 50px;
    height: 50px;
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    color: white;
    border: none;
    border-radius: 50%;
    opacity: 0;
    visibility: hidden;
    transition: all 0.3s ease;
}

.back-to-top.show {
    opacity: 1;
    visibility: visible;
}
```

**JavaScript逻辑：**
```javascript
// 滚动监听
window.addEventListener('scroll', function() {
    if (window.pageYOffset > 300) {
        backToTopBtn.classList.add('show');
    } else {
        backToTopBtn.classList.remove('show');
    }
});

// 点击返回
backToTopBtn.addEventListener('click', function() {
    window.scrollTo({
        top: 0,
        behavior: 'smooth'
    });
});
```

### 安装程序核心代码

**进度跟踪：**
```php
$install_steps = [];
$current_step = 0;

// 步骤1
$current_step = 1;
$install_steps[] = ['step' => 1, 'name' => '创建数据目录', 'status' => 'processing'];
// 执行操作...
$install_steps[0]['status'] = 'success';

// 错误处理
catch (Exception $e) {
    $install_steps[$current_step - 1]['status'] = 'error';
    $install_steps[$current_step - 1]['error'] = $e->getMessage();
}
```

**URL生成：**
```php
$protocol = (!empty($_SERVER['HTTPS']) && $_SERVER['HTTPS'] !== 'off') ? 'https://' : 'http://';
$host = $_SERVER['HTTP_HOST'];
$base_url = $protocol . $host . dirname($_SERVER['PHP_SELF']);
$frontend_url = $base_url . '/index.php';
$backend_url = $base_url . '/admin/';
```
