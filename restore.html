🚨 紧急恢复指南

商用菜谱库 - 代码压缩问题恢复

⚠️检测到严重问题

问题：代码压缩功能出现错误，导致网站无法访问

原因：压缩规则将字符串内容错误替换为占位符

影响：前端和后台都无法正常访问

🔧 立即恢复方法

1通过FTP/SSH连接服务器

使用FTP客户端（如FileZilla）或SSH连接到您的服务器

2找到备份文件

进入网站根目录，找到 backups 文件夹

备份文件格式：backup_2026-01-18_XX-XX-XX.zip

选择最新的备份文件（日期时间最近的）

3下载备份文件

将备份ZIP文件下载到本地电脑

4解压备份文件

在本地电脑上解压ZIP文件

会得到 admin 文件夹和根目录的PHP文件

5上传并覆盖文件

通过FTP将解压后的所有文件上传到网站根目录

选择覆盖现有文件

6测试网站

访问网站前端和后台，确认恢复成功

🎛️ 宝塔面板用户

使用宝塔面板恢复（更简单）

  1. 登录宝塔面板
  2. 点击左侧 文件 菜单
  3. 进入网站根目录
  4. 找到 backups 文件夹
  5. 找到最新的 backup_*.zip 文件
  6. 右键点击该文件，选择 解压
  7. 解压路径选择网站根目录（上一级）
  8. 确认覆盖现有文件
  9. 等待解压完成
  10. 访问网站测试

💻 命令行恢复（高级用户）

如果您熟悉命令行，可以使用以下命令：

# 进入网站根目录
cd /var/www/html

# 查看备份文件
ls -lh backups/

# 解压最新备份（替换为实际文件名）
unzip -o backups/backup_2026-01-18_XX-XX-XX.zip

# 设置权限
chmod -R 755 .
chown -R www-data:www-data .  # Ubuntu/Debian
# 或
chown -R apache:apache .      # CentOS/RHEL

📋 如果没有备份文件

备份文件不存在的解决方案

  1. 服务器快照：检查服务器管理面板是否有自动快照功能
  2. 宝塔备份：宝塔面板可能有自动备份，检查备份管理
  3. Git版本控制：如果使用Git，可以回退到之前的提交
  4. FTP备份：检查本地是否有之前下载的文件
  5. 联系服务商：询问服务器提供商是否有备份

🔄 Git回退方法

如果您使用Git版本控制：

# 查看提交历史
git log --oneline

# 回退到压缩前的提交（替换为实际commit ID）
git reset --hard abc1234

# 如果已推送到远程，需要强制推送（谨慎使用）
git push -f origin main

✅ 恢复后必做事项

重要：恢复后立即执行

  1. 删除压缩功能
    • 删除文件：admin/compress.php
    • 或从后台导航菜单中移除该功能
  2. 删除恢复文件
    • 删除：emergency_restore.php
    • 删除：restore.html
    • 删除：紧急恢复说明.txt
  3. 测试所有功能
    • 前端页面访问
    • 后台登录
    • 菜谱管理
    • 分类管理
    • 页面管理
  4. 创建新备份
    • 手动备份整个网站
    • 或使用宝塔面板的备份功能

🛡️ 预防措施

避免再次出现问题

  • 定期备份：每周至少备份一次，保留多个版本
  • 使用Git：版本控制可以随时回退
  • 测试环境：新功能先在测试环境测试
  • 专业工具：如需压缩，使用成熟的第三方工具
  • 不要使用有问题的压缩功能
